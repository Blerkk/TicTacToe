# Tic-Tac-Toe Game

A simple Tic-Tac-Toe game with a graphical user interface built using DearPyGui.

## Features

- Play against AI with multiple difficulty levels
- Two-player mode
- Score tracking
- Modern UI

## Installation

```bash
# Clone the repository
git clone https://github.com/Blerkk/TicTacToe.git
cd TicTacToe

# Set up virtual environment
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt
